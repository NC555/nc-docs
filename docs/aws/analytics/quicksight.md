# Amazon QuickSight

<div class="aws__ImageCentered">
<img style={{ width: '96px', overflowX: 'auto' }} src="/img/aws/logo/analytics-quicksight.png" alt="Amazon QuickSight" />
</div>

With Amazon QuickSight, both technical and non-technical users can quickly create modern interactive dashboards and reports from various data sources without managing infrastructure. It allows everyone in an organization to understand data by asking questions in natural language.

## Core Benefits

- **Serverless and Scalable:** Automatically scales to tens of thousands of users without any servers to manage.
- **Interactive Visualizations:** Create rich, interactive dashboards that can be embedded in applications and websites.
- **Natural Language Queries:** Amazon Q in QuickSight allows users to ask questions in plain English and get instant answers as visualizations.

## Role in Data Pipeline

**Data Visualization:** Acts as the final step in the data pipeline, connecting to data sources like Redshift, Athena, and S3 to transform data into meaningful visual insights for business users.

## Use Cases

- **Executive Dashboards:** Building high-level dashboards to track key business metrics (KPIs) for leadership.
- **Operational Reporting:** Creating detailed, interactive reports for sales, marketing, and operations teams to analyze performance.

:::info
Amazon QuickSight makes business intelligence accessible to everyone, enabling data-driven decision-making across an organization.
:::

**Use case:** Ideal for creating and sharing interactive dashboards and BI reports across an organization, from analysts to business leaders.
