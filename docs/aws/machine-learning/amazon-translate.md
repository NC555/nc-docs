# Amazon Translate

<div class="aws__ImageCentered">
<img style={{ width: '96px', overflowX: 'auto' }} src="/img/aws/logo/ml-translate.png" alt="Amazon Translate" />
</div>

Amazon Translate is a neural machine translation service that provides fast, high-quality, and affordable language translation. The service supports real-time and batch text translation across multiple languages, enabling global communication and content localization at scale.

## Core Benefits

**Neural Translation Quality:** Leverages advanced neural machine translation models to deliver fluent, contextually accurate translations that understand nuance and maintain meaning across languages.

**Extensive Language Support:** Supports translation between dozens of languages including major global languages and regional dialects for comprehensive international communication needs.

**Flexible Processing Options:** Offers both real-time translation for interactive applications and batch processing for large-scale content localization projects with cost-effective pricing models.

**Custom Translation Models:** Enables training of custom translation models using domain-specific terminology and content for specialized industries and use cases requiring precise translations.

## Use Cases

### Global E-commerce Localization
International retailers use Translate to localize product descriptions, customer reviews, and marketing content across multiple languages and regions. The service enables dynamic translation of user-generated content while maintaining consistent brand messaging and product information accuracy.

### Customer Support Globalization
Multinational companies deploy Translate to enable multilingual customer support by translating support tickets, knowledge base articles, and chat conversations in real-time. The service allows support teams to assist customers in their native languages without requiring multilingual staff.

### Content Publishing and Media
News organizations and content publishers leverage Translate to quickly localize articles, blog posts, and multimedia content for global audiences. The service accelerates content distribution while maintaining editorial quality and enabling rapid response to international news events.

### Software Application Internationalization
Technology companies use Translate to localize user interfaces, help documentation, and in-app content for global software distribution. The service supports dynamic translation of user-generated content and enables applications to serve users in their preferred languages.

### Legal and Financial Document Translation
Professional services firms deploy Translate for initial translation of contracts, financial reports, and regulatory documents across multiple jurisdictions. The service provides foundation translations that legal and financial experts can review and refine for accuracy.

## Key Features

Translate offers automatic language detection to identify source languages automatically and supports custom terminology for consistent translation of industry-specific terms. The service provides confidence scores and maintains formatting for various document types.

## Shared Responsibility Model

**AWS Responsibilities:** Amazon manages the neural translation infrastructure, language model training and updates, service availability, and security of the translation processing pipeline.

**Customer Responsibilities:** You handle source content preparation, translation quality validation, custom model training for specialized domains, and ensuring appropriate use of translated content for intended audiences and compliance requirements.

:::info
Translate breaks down language barriers by providing enterprise-grade neural machine translation that enables global communication and content localization without specialized translation infrastructure.
:::

**Use case:** Ideal for organizations requiring multilingual capabilities, from global e-commerce and customer support to content publishing and software internationalization across diverse markets.
