# Pre-built AWS AI Services (Tier 1)

The AWS AI services tier is made up of pre-built models that are already trained to perform specific functions. These ready-to-use, managed services help you quickly solve a variety of business use cases without requiring deep machine learning expertise or managing underlying infrastructure.

## Language Services

AWS AI language services are designed to interpret text or speech and transform it into meaningful insights.

| **Amazon Polly**      |      <img src="/img/aws/logo/ml-polly.png" alt="Amazon Polly" width="64"/>      | - Converts text into lifelike speech.<br/>- Supports multiple languages, genders, accents.<br/>- Uses advanced deep learning technologies.<br/>              | - Virtual assistants.<br/>- E-learning applications.<br/>- Accessibility enhancements for visually impaired users.<br/> |
| **Amazon Transcribe** | <img src="/img/aws/logo/ml-transcribe.png" alt="Amazon Transcribe" width="64"/> | - Converts speech into text.<br/>- Supports multiple languages and real-time transcription.<br/>- Offers speaker identification and custom vocabulary.<br/>  | - Customer call transcription.<br/>- Automated subtitling.<br/>- Metadata generation for media content.<br/>            |
| **Amazon Translate**  |  <img src="/img/aws/logo/ml-translate.png" alt="Amazon Translate" width="64"/>  | - Text translation service.<br/>- Supports real-time and batch translation.<br/>- Ideal for global communication across multiple languages.<br/>             | - Document translation.<br/>- Multi-language application integrations.<br/>- Localizing website content.<br/>           |
